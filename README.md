# CleanOps - Sistema de Gestión de Limpieza Profesional

## Descripción
Aplicación web profesional para la gestión de servicios de limpieza, incluyendo control de empleados, clientes, incidencias, facturación y más.

## Estructura del Proyecto
```
cleanops/
├── src/          # Código fuente
├── docs/         # Documentación
├── tests/        # Tests automatizados
└── .github/      # Configuración de CI/CD
```

## Tecnologías
- HTML5, CSS3, JavaScript (Vanilla)
- GitHub Pages para despliegue gratuito
- Futuro: Vite, React/Vue, Node.js

## Despliegue
El proyecto se despliega automáticamente en GitHub Pages al hacer push a la rama main.
