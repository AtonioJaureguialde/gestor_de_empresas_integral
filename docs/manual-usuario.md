# Manual de Usuario - CleanOps

## Introducción
CleanOps es una plataforma integral para la gestión de servicios de limpieza profesional.

## Módulos Principales

### 1. Calendario
- Visualización de servicios programados
- Arrastrar y soltar para reprogramar
- Vista diaria, semanal y mensual

### 2. Servicios
- Catálogo de servicios ofrecidos
- Precios y duraciones
- Asignación a clientes

### 3. Incidencias
- Reporte de incidencias en tiempo real
- Fotos y evidencias
- Seguimiento de resolución

### 4. Chat
- Comunicación interna entre equipo
- Notificaciones push
- Historial de conversaciones

### 5. Facturación
- Generación de facturas automáticas
- Control de pagos
- Exportación a PDF/CSV

### 6. Reportes
- Métricas de rendimiento
- Horas trabajadas
- Ingresos por periodo

### 7. Rutas
- Optimización de rutas GPS
- Check-in/check-out geolocalizado
- Cálculo de distancias (Fórmula Haversine)

### 8. Portal del Cliente
- Acceso para clientes
- Historial de servicios
- Aprobación de trabajos

### 9. Clientes
- Gestión de cartera de clientes
- Datos de contacto
- Historial de servicios

### 10. Empleados
- Perfiles de empleados
- Horarios y disponibilidad
- Rendimiento y evaluaciones

## Funcionalidades Destacadas

### Check-in con GPS
- Validación de ubicación al iniciar servicio
- Registro automático de hora de llegada

### Evidencias Fotográficas
- Captura de fotos antes/después
- Marcado de fecha y ubicación

### Firma Digital
- Firma en canvas táctil
- Almacenamiento seguro

### Códigos QR
- Generación de QR por servicio
- Escaneo para validación

### Notificaciones
- Alertas de nuevos servicios
- Recordatorios de citas
- Actualizaciones de estado

### Exportación de Datos
- PDF para informes
- CSV para análisis
- ICS para calendarios externos

## Primeros Pasos

1. **Login:** Ingresa con tus credenciales
2. **Dashboard:** Vista general del día
3. **Navegación:** Usa el menú lateral para acceder a módulos
4. **Configuración:** Personaliza tu perfil y preferencias
